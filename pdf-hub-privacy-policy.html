01

Commitment & Application Scope

Welcome to the official Privacy Policy for PDF Hub : PDF Editor & Tools (referenced as "PDF Hub", "the Application", "we", "us", or "our"), developed and published by Krishna Tech Hub.

We fundamentally believe that privacy is a non-negotiable human right. Documents, tax filings, legal agreements, receipts, personal photo albums, and study notes handled inside a PDF utility are highly confidential. This Privacy Policy outlines our transparent architecture: PDF Hub is designed from the ground up as an offline-first, client-side utility where all file transformations happen directly on your smartphone processor without remote intermediary servers.

Our Guiding Architectural Promise

Your documents never touch our servers because we do not operate any document ingestion, storage, or processing servers. Your device does 100% of the computation.

03

Android Permissions & Technical Rationale

To execute offline document manipulations, PDF Hub requests standard Android system permissions. Each permission is strictly bounded to user-initiated actions:

READ_MEDIA_IMAGES (Android 13+)

Granular Photo Access

Enables you to browse and select images from your gallery to convert them into multi-page PDF documents or run image compression. Active only when you explicitly select photos via Android's native photo picker.

READ_EXTERNAL_STORAGE (Android ≤ 12)

Legacy Storage Read

On legacy Android operating systems, this allows the app to open the PDF or image file you specifically select from your device's file explorer for merging, splitting, or reordering.

WRITE_EXTERNAL_STORAGE (Android ≤ 9)

Save Generated Files

Permits writing the resulting output document (such as a compressed PDF or converted image) to your local "Downloads" or "Documents" directory so you can access it anywhere on your phone.

CAMERA (Optional)

Document Scanner

Required only if you choose to use the built-in document camera scanner to photograph a physical paper or receipt. Camera frames are processed strictly in real-time memory and never uploaded.

INTERNET

Network Connectivity

Declared for Google Play Services integrity checks, crash telemetry (if enabled by OS), and Google AdMob ad requests. Document and image processing modules have zero programmatic access to the network socket.

ACCESS_NETWORK_STATE

Connection Health

Allows the application to determine whether an active internet connection is available before sending standard ad requests or opening external Play Store links.

User Control Over Permissions

You can grant, deny, or revoke any permission at any moment via your phone's Settings → Apps → PDF Hub → Permissions. Denying optional permissions (like Camera) will merely disable the physical camera scanning feature without hindering offline PDF file editing.

04

On-Device Processing Architecture

Unlike cloud-based PDF conversion portals that require you to upload confidential files over the web to a remote server farm, PDF Hub executes all algorithms locally via compiled native libraries:

  • ✔
    Native Document Manipulation (iText 7 / PDFBox Engine) Splitting, merging, rotating, watermarking, password encryption, and page reordering run entirely within the isolated application sandbox.
  • ✔
    Hardware-Accelerated Image Compression Image-to-PDF conversion, resolution downsampling, cropping, and format transcode (PNG, JPG, WebP) utilize the device's native hardware canvas without external API calls.
  • ✔
    Immediate Volatile Cache Purge Temporary processing buffers allocated in RAM during a batch merge or compress operation are automatically garbage collected and purged as soon as the task completes or the screen is closed.

06

Data Storage, Retention & Deletion

Because we do not upload files to remote servers, your documents remain under your absolute physical custody:

  • ✔
    Storage Location: Output PDFs and compressed media are saved directly to your local file system (e.g., /Internal Storage/Documents/PDFHub/).
  • ✔
    Direct Instant Deletion: You can delete any processed file at any second using PDF Hub's built-in file browser or any system file manager (Files by Google, Samsung My Files, etc.). Deleted files are permanently purged from flash storage without residual cloud backups.
  • ✔
    App Uninstall: Uninstalling PDF Hub completely removes the application binary, private caches, and internal preferences from your device.
07

Device-Level Security Measures

Security is built into PDF Hub through Android operating system-level sandboxing:

• Process Sandboxing: Android isolates each app in its own Linux UID container. Other installed apps cannot inspect PDF Hub's internal memory buffers.
• Scoped Storage Compliance: We adhere to Google's Scoped Storage architecture (Android 10+), preventing arbitrary broad file reads.
• No Server Attack Surface: Because there are no backend user databases, there is zero risk of third-party server credential stuffing or data breach incidents compromising your documents.

08

Children's Privacy Protection (COPPA / Family Policy)

PDF Hub is a neutral productivity tool designed for general audiences. We do not knowingly collect, solicit, or maintain personally identifiable information from children under the age of 13 (or under 16 in the European Union).

Because the application does not have user accounts, profile registration, or server-side data ingestion, children can use the document utility safely with zero risk of personal identity exposure. If you are a parent or guardian and believe your child provided personal information through our support email, please contact us immediately to erase it.

Global Privacy Rights (GDPR / CCPA / CalOPPA)

Depending on your jurisdiction (such as the European Economic Area under GDPR, California under CCPA/CPRA, or Brazil under LGPD), you enjoy specific privacy rights:

  • ⚖️
    Opt-Out of Personalized Advertising: You can reset or opt out of personalized ad targeting at any time on your Android device via: Settings → Google → Ads → Reset advertising ID or Delete advertising ID.
  • ⚖️
    Non-Discrimination: We never deny features, degrade performance, or charge different prices based on exercising your statutory privacy rights.
